Log conversion (HTTP 402)

Free traffic hits a gated route and gets HTTP 402 Payment Required—not a hard deny, a price tag. Agents (or wallets) settle a small USDC micropayment, retry with a payment signature, and the tollgate unlocks the upstream response. The same loop works for MCP tools: discover → 402 → pay → unlock. No API keys, no monthly billing SaaS—conversion is the protocol.

Self-host (open source)

MIT. One process: HTTP gateway + Streamable HTTP MCP. Point it at your upstream API.

npx x402-micro-tollgate
# or
docker compose up

Set three env vars for live settlement: CDP_API_KEY_ID, CDP_API_KEY_SECRET, X402_PAY_TO. Optional: UPSTREAM_URL, PRICE.

What you get

HTTP gateway

Gate /v1/* with x402. Unpaid → 402 + PAYMENT-REQUIRED. Paid → proxy to your API. /health stays free.

MCP tools

server_info free. get_quote and proxy_request charge per call. Drop into Cursor / Claude Desktop.

Cursor config

After you expose the server (local or public), paste this into mcp.json.

{
  "mcpServers": {
    "x402-micro-tollgate": {
      "url": "http://127.0.0.1:8402/mcp"
    }
  }
}
